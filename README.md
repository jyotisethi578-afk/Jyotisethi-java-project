# Contact Management Directory System

## Project Description
The Contact Management Directory System is a Core Java based application developed to store, manage, search, update, and delete contact information efficiently. The project demonstrates the implementation of Object-Oriented Programming (OOP) concepts.

## Features
- Add Contact
- View Contacts
- Search Contact
- Update Contact
- Delete Contact
- Menu Driven Interface

## Technologies Used
- Core Java
- Object-Oriented Programming (OOP)
- VS Code / Eclipse
- Git & GitHub

## OOP Concepts Used
- Class and Object
- Encapsulation
- Abstraction
- ArrayList
- Methods and Functions

## How to Run
1. Install Java JDK.
2. Open the project in VS Code or Eclipse.
3. Compile all Java files.
4. Run the `ContactDirectorySystem.java` file.
5. Use the menu to perform contact management operations.

## Project Structure
- Contact.java
- ContactManager.java
- ContactDirectorySystem.java
- Service.java (if applicable)
